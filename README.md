# Task Management Backend Scaffold

This is a starter Node.js + Express project structure for a task management backend.

## Structure

- `src/index.js` - app entry point
- `src/routes/taskRoutes.js` - task API routes
- `src/controllers/taskController.js` - simple controller logic
- `src/models/` - place for task data models
- `src/middleware/` - place for middleware
- `src/config/` - place for configuration

## Scripts

- `npm install`
- `npm run dev`
- `npm start`

## Notes

- The project includes a basic task CRUD route placeholder.
- No database is configured yet.
- Use `.env` to set `PORT`.
